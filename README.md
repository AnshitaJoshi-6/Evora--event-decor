
# ✨ ÉVORA — Event Decoration & Styling

> **We design moments.**

ÉVORA is a modern event decoration and styling website designed to help users plan and visualize beautiful celebrations based on their **occasion, preferred style, and budget**.


## What is ÉVORA?

ÉVORA is a digital platform for event decoration where users can:

* Explore different event occasions
* Discover decoration styles and themes
* Browse decoration services
* Explore previous event setups
* View decoration packages
* Create a customized event concept based on their preferences
* Submit an event enquiry

The main interactive feature, **Create Your Event**, allows users to select their occasion, aesthetic, and budget to generate a suitable decoration concept.

## ⭐ Key Feature

### Create Your Event

Users can choose:
**Occasion → Style → Budget → Decoration Concept**

The website then presents a customized setup including elements such as:
* Floral decorations
* Backdrops
* Lighting
* Table styling
* Photo corners

This makes ÉVORA more than a simple decoration portfolio — it acts as a **mini event-planning experience**.
